# Деградация сервисов — инфографика

PostgreSQL 18 + Adminer + NGINX + PHP-FPM 8.4, фронтенд на чистом JS без библиотек.

## Запуск

```sh
docker compose up -d --build
```

| Что | Адрес |
|---|---|
| Дашборд | http://localhost:8000 |
| Adminer | http://localhost:8080 (сервер `db`, пользователь `postgres_admin`, пароль `example`, база `testdb`) |
| PostgreSQL | localhost:5432 |

Если порты заняты: `DB_HOST_PORT=55432 ADMINER_HOST_PORT=8081 WEB_HOST_PORT=8001 docker compose up -d`.

## Данные

Схема — в `db/01-schema.sql`, демо-данные — в `db/02-data.sql`. Postgres загружает их сам при первом старте с пустым томом.

Каждый случай деградации хранится отдельной строкой `degradation_case` с диапазоном деградации `bucket_id` и датой `case_date`. Точный процент не хранится: авария определяется тем, в какой диапазон с шагом 10 она попала (таблица `bucket`: 0–10%, 11–20%, … 91–100%). Данные есть за каждый месяц с сентября 2025 по октябрь 2026; на дашборде месяц выбирается в списке «Месяц» (по умолчанию — последний). Степени деградации (минимальная, частичная, значительная, полная — названия по МУ) считаются по диапазону, границы по умолчанию: минимальная 0–20%, частичная 21–50%, значительная 51–80%, полная 81–100% (`STEPEN_BOUNDS` в `public/js/config.js`). У отдельного сервиса можно задать свои границы: нажать на его название (чип) в таблице, в окне «Индивидуальные границы деградации» задать границы числами или стрелками (шаг 10%) и сохранить; «Сбросить» возвращает в поля границы по умолчанию (применяются тоже по «Сохранить»). У чипа такого сервиса чёрная обводка. Свои границы живут только на странице (`state.serviceBounds`): на сервер не отправляются, при смене месяца сохраняются, после перезагрузки страницы сбрасываются. Продукты 1–3 в данных (таблица `product`) — верхний уровень: в продукте операции, в операции сервисы. Диапазоны `bucket` задают и колонки таблицы «как в Excel».

**Демо-данные синтетические.** Октябрь 2026 — данные из `пример.xlsx`: количество случаев по диапазонам совпадает с исходной таблицей, даты — с 1 по 10 октября. Сентябрь 2025 — сентябрь 2026 сгенерированы по образцу октября. Когда будут реальные данные, их нужно загрузить вместо блока `degradation_case` в `db/02-data.sql`.

Чтобы перезалить данные после правки этих файлов:

```sh
docker compose down -v && docker compose up -d
```

## Структура

```
compose.yaml, Dockerfile     PostgreSQL (ru_RU, ICU) + Adminer + php + nginx
db/                          схема и демо-данные
docker/php/Dockerfile        php-fpm с pdo_pgsql
docker/nginx/default.conf    статика из public/, /api/* -> src/api.php
src/api.php                  JSON API: GET /api/data?month=2026-10 — данные за месяц одним ответом
public/                      index.html, style.css
public/js/                   app.js — точка входа; config, state, calc, dom, view, service-dialog — модули страницы
                             (что в каком файле и кто кого подключает — в начале app.js)
```
