# Деградация сервисов

Дашборд по случаям деградации сервисов. PostgreSQL 18, FastAPI, React + Vite (SCSS), всё крутится в Docker.

## Запуск

```sh
docker compose up -d --build
```

- дашборд: http://localhost:8000
- Swagger: http://localhost:8000/api/docs
- Adminer: http://localhost:8080 (сервер `db`, логин `postgres_admin`, пароль `example`, база `testdb`)
- Postgres: localhost:5432

Если порты заняты, их можно переопределить:

```sh
DB_HOST_PORT=55432 ADMINER_HOST_PORT=8081 WEB_HOST_PORT=8001 docker compose up -d
```

Код копируется в образ при сборке, поэтому после правок нужно пересобрать сервис:

```sh
docker compose up -d --build backend
docker compose up -d --build frontend
```

Фронт удобнее править через dev-сервер Vite (нужен Node 22+):

```sh
cd frontend
npm install
npm run dev
```

Он поднимется на http://localhost:5173 и будет проксировать `/api` в запущенные контейнеры.

## Как устроено

```
браузер -> frontend (nginx, :8000) -> статика React
                                   -> /api/* -> backend (FastAPI) -> db (PostgreSQL)
```

Фронт собирается внутри образа (`npm run build`), nginx отдаёт статику и проксирует `/api/*` на бэкенд.

На бэкенде один эндпоинт:

```
GET /api/data?from=2026-01-01&to=2026-03-31
```

Отдаёт все данные для дашборда за период. Без `from`/`to` берётся последний месяц, за который есть данные. Ошибки приходят в виде `{"error": "..."}`: 400 на неправильные даты, 404 если случаев нет или такого роута нет, 500 при ошибке БД.

## Данные

Схема лежит в `db/01-schema.sql`, демо-данные в `db/02-data.sql`. Postgres подхватывает их сам при первом запуске на пустом томе. Перезалить:

```sh
docker compose down -v && docker compose up -d
```

Иерархия: продукт → операция → сервис. Каждый случай деградации хранится строкой в `degradation_case` с датой (`case_date`) и диапазоном (`bucket_id`). Точный процент не храним, только диапазон с шагом 10%: 0–10, 11–20, …, 91–100 (таблица `bucket`). По этим же диапазонам строятся колонки в таблице на дашборде.

Демо-данные ненастоящие и покрывают период с сентября 2025 по октябрь 2026. Октябрь 2026 взят из `пример.xlsx`: количество случаев по диапазонам совпадает, даты раскиданы с 1 по 10 октября. Остальные месяцы сгенерированы по его образцу. Когда появятся реальные данные, их надо залить вместо блока `degradation_case` в `02-data.sql`.

## Степени деградации

Диапазоны группируются в четыре степени (названия взяты из МУ):

| Степень | По умолчанию |
|---|---|
| минимальная | 0–20% |
| частичная | 21–50% |
| значительная | 51–80% |
| полная | 81–100% |

Дефолтные границы задаются в `STEPEN_BOUNDS` (`frontend/src/config.js`).

Для отдельного сервиса границы можно поменять прямо на странице: клик по чипу сервиса в таблице открывает окно со слайдером. Ненужную степень можно выключить, тогда её диапазон забирает соседняя. Сервисы со своими границами обведены чёрным. Эти настройки живут только в стейте (`serviceBounds` в `App.jsx`), на сервер не уходят и пропадают после перезагрузки страницы.

## Период и фильтры

Период выбирается в верхней панели: месяц, год или произвольный диапазон дат. По умолчанию открыт последний месяц, а в режиме диапазона выбраны все данные. Там же фильтр по продукту. Бэкенд всегда получает две даты, месяц и год переводятся в них на фронте (`frontend/src/period.js`).

## Структура

```
compose.yaml            db, adminer, backend, frontend
docker/db/Dockerfile    Postgres с русской локалью (ICU)
db/                     схема и демо-данные

backend/
  app/main.py           роут /api/data, проверка дат, ошибки
  app/data.py           запросы к БД и сборка ответа
  app/db.py             подключение к БД

frontend/
  Dockerfile, nginx.conf
  public/               шрифты, иконка
  src/main.jsx          точка входа
  src/App.jsx           вся страница: стейт и загрузка данных
  src/components/       компоненты, у каждого своя папка (Donut/Donut.jsx + Donut.scss)
  src/*.js              расчёты и утилиты без React: calc, bounds, period, api, helpers, config
  src/styles/           global.scss (шрифты, цвета, базовые стили) и _mixins.scss
```
